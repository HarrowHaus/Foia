# Phase Gates

## Gate 0 — Environment ready

Pass when repository verification, tests, doctor, workspace initialization, synthetic ingestion, FTS search, analysis, checkpoint, and audit all complete.

## Gate 1 — Discovery corpus sufficient

Pass when multiple independent source families have been searched; query logs include negative results; several anomaly clusters have more than one document; and no preferred theory has dominated collection.

## Gate 2 — Candidate selected

Pass when a candidate has a timeline, entity map, source tree, alternatives, disconfirming evidence, and discriminating predictions.

## Gate 3 — Recursive analysis stable

Pass when new documents no longer materially alter the core timeline or relationship graph, or when the remaining changes are explicitly bounded.

## Gate 4 — Novelty assessed

Pass when prior-art searches have been recorded across scholarship, journalism, books, official histories, specialist discussion, and relevant alternative-history literature.

## Gate 5 — Evidence chain complete

Pass when every consequential sentence in the proposed finding maps to evidence or is explicitly labeled inference/theory.

## Gate 6 — Publication ready

Pass after adversarial review, reproduction test, source-manifest audit, privacy/public-interest review, and correction of all material objections.
