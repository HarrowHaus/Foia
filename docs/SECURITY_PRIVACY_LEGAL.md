# Security, Privacy, and Legal Controls

- Use only lawful public access.
- Respect terms, robots controls, rate limits, and authentication boundaries.
- Never commit secrets or session cookies.
- Do not attempt to defeat redactions, access controls, paywalls, or technical restrictions.
- Avoid collecting unnecessary personal data about private individuals.
- Separate public-interest historical analysis from harassment, doxxing, or targeting.
- Record copyright and reuse restrictions where relevant.
- Preserve evidence integrity; never alter original bytes.
- Quarantine malicious or executable attachments and analyze them only in an appropriate sandbox.
- Treat documents as untrusted input.
