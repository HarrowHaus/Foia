# Redaction Differential Method

## Objective

Compare multiple public versions of what appears to be the same record without guessing hidden text.

## Match signals

- document number;
- title and date;
- routing fields;
- page count;
- paragraph sequence;
- repeated unredacted phrases;
- archive identifier and release batch;
- scan geometry or Bates numbering.

## Output

- version pair;
- match confidence;
- page alignment;
- added, removed, or changed visible text;
- redaction marker count and position;
- classification marking differences;
- release dates;
- an explicit statement that unreleased content is unknown.

Never reconstruct hidden words as fact from context alone.
